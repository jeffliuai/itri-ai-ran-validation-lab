背景與目的

本頁整理 ITRI AI-RAN / OCUDU Validation Lab 的初步工作分解，用來對齊內部對實驗室定位、年度目標與執行優先序的共識。

目前的核心判斷是：ITRI 不只是建立單一測試能力，而是要逐步形成一個能支援台灣設備商與 AI-RAN 解決方案進入國際 OCUDU / AI-RAN 驗證鏈的中立驗證場域。短期先從 OCUDU + real O-RU interoperability 做起，累積可被外部生態系接受的 proof objects；中期延伸到 Neural Receiver、rApp 與 Digital Twin validation。

這份文件不是最終執行計畫，而是第一版目標架構與 WBS 草案。重點是先確認方向是否正確，再展開 owner、時程、資源與風險管理。

Massive Beams × OCUDU Testbed 論文重點（arXiv:2607.05146）

來源：Massive Beams MODRAD-SC × OCUDU：模組化 O-RAN Testbed 與 FR3 NFED-RIS Beamforming 實證（SRS + 德國新創 Massive Beams + TU Berlin，2026-07-06）

核心技術亮點：

  • 同一硬體雙模式免重配線切換：MODRAD-SC 可在 CAT-A O-RU 標準模式（split 7.2a）與純 SDR 模式（split 8）間切換，共用同一 25 Gbit/s SFP28 連結
  • FR3 NFED-RIS Hybrid Beamforming 實測：近場饋入 RIS（8×8 陣列、2-bit 相移器），fc=7.2GHz over-the-air 驗證，beam ID 透過 O-RAN C-Plane Section Type 1（10-bit，800 個 beam ID）傳遞
  • 使用案例：multi-user/massive MIMO、cell-free MIMO、波形研發、ISAC/RF imaging、NTN signaling、FR1/FR3 coexistence、AI-driven network management

關鍵限制：論文標題強調的「massive MIMO」「64T64R」「Giga-MIMO 256 elements」都是 Massive Beams 未來路線圖，本文實際驗證只是 8×8 RIS beam-steering 的小規模 demo，規模遠小於摘要給人的印象。

對今天 WBS 更新的意義：這是一個歐洲小型新創（非 SRS 自家團隊）完成 OCUDU + 第三方 RU 完整端到端整合並發表論文的具體範本，抬高了「evidence grammar」的最低標準——是 C1.4 新增備註的依據。

目標：成為台灣通訊產業鏈進入 AI-RAN / OCUDU 國際驗證鏈的槓桿。

ITRI 的核心價值在於建立具備 OCUDU integration、real O-RU interoperability、Neural Receiver / AI-RAN validation、compute path readiness 的中立驗證場域，協助台灣通訊產業鏈廠商降低進入國際生態系的門檻（短期聚焦 RU 廠商，長期延伸至產業鏈各層次）。
